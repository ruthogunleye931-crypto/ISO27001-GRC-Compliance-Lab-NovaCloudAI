# ISO 27001 GRC Compliance Lab – NovaCloud AI Solutions

## Project Overview

This project simulates a real-world Governance, Risk, and Compliance (GRC) exercise for a fictional cloud-based technology company, **NovaCloud AI Solutions**.

The objective was to build a mini compliance program aligned with **ISO 27001 Annex A 2022** controls.

## Scope

The assessment covered:

- Staff devices and hardware assets
- AWS cloud infrastructure
- Google Workspace
- SaaS collaboration tools
- Customer databases
- Access management systems
- Information security governance controls

## Deliverables

### 1. Asset Register
Created a structured inventory of organizational assets including:

- Hardware
- Cloud systems
- SaaS platforms
- Data assets
- Ownership
- Classification levels
- Criticality ratings

### 2. ISO 27001 Control Implementation Tracker
Performed a control assessment using selected ISO 27001 Annex A controls.

Activities included:

- Control mapping
- Gap assessment
- Status evaluation
- Ownership assignment
- Remediation planning

### 3. Compliance Summary Report
Produced a concise security assessment report outlining:

- Assessment scope
- Compliance objective
- Key control gaps
- Recommended remediation actions

## Key GRC Skills Demonstrated

- ISO 27001 Annex A Control Mapping
- Asset Inventory Management
- Gap Assessment
- Security Governance
- Risk Identification
- Compliance Documentation
- Control Ownership Tracking
